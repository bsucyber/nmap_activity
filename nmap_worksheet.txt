Nmap is a great tool for gathering info on targets. The following questions are some common things to check when doing recon.
They may seems unrelated to each other, but the more you learn about a target, the easier it is to find vulnerabilities.

1. Run a basic scan on this domain and save the results to a file.
	domain: scanme.nmap.org

	Questions:
		a) What ports are open?
	
		b) How many ports were filtered by the firewall?

		c) What "service" is using the highest open port?


2. That default scan is fairly stealthy, but we want more info and we want it quickly. 
   This means we need to use more aggressive scanning options.

   Run a scan that gives us specific versions of the services being used. 
   Also speed up the timing of the packets to the second highest setting.

	
	Questions:
		a) What version of ssh is the server using?

		b) Did any of the listed services change? Why?
		
		



3. Run a default script scan against the target, but to save time, only scan the ports you know are open.
	Questions:
		a) What is the title of the web page on port 80?
	
		b) The ssh-hostkey script provides several cryptographic fingerprints for the SSH server. What is the SHA256 hash it displays?




4. We've identified open ports, service versions, and gathered details with scripts. 
   Now let's try to determine the underlying operating system of the server 
   and the network route our packets take to get there.

   Run a scan that enables OS detection and traceroute.

	Questions:
		a) What is the OS?
		b) How many network hops are between you and the server?






5.Putting it all together:
	At this point we have gathered quite a bit of info on this server. If we were performing a pentest we could use that info to look for vulnerabilites.
	
	Question:
		a) What vulnerability is associated with OpenSSH < 7.7 that allows user enumeration (Answer with the CVE number)

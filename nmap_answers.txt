Answers for the nmap activity


1. Run a basic scan on this domain and save the results to a file.  
	domain: scanme.nmap.org

Scan: sudo nmap scanme.nmap.org -On scan_output.txt
	Questions:
		a) What ports are open? 22, 80, 9929, 31337
	
		b) How many ports were filtered by the firewall? 996

		c) What "service" is using the highest open port? Elite




2. That default scan is fairly stealthy, but we want more info and we want it quickly. 
   This means we need to use more aggressive scanning options.

   Run a scan that gives us specific versions of the services being used. 
   Also speed up the timing of the packets to the second highest setting.

Scan: sudo nmap scanme.nmap.org -sV -T4
	Questions:
		a) What version of ssh is the server using? OpenSSH 6.6.1p1

		b) Did any of the listed services change? Why? port 31337 changed from elite to tcpwrapped. This has to do with how nmap initially checks what services are running. It uses a database to "guess" the service unless -sV is used. In this case elite is not a real service but rather a meme based on internet culture. tcpwrapped is also just telling us that a connection is made and then immediately closed.

   Run a scan that enables traceroute and use the option to disable port scanning.
Scan" sudo nmap scanme.nmap.org --traceroute -sn
